# AGENTS.md

本文件是本前端项目的协作入口与自检清单。**每次写代码前先读对应规范，写完对照自检，违反即改。**

## 索引

- **《设计规范》** → `docs/design-tokens.md`：颜色、圆角、阴影、间距、字号、布局、视觉基准的可校验条款。
- **《开发规则》** → `docs/dev-rules.md`：目录结构、组件复用、接口契约、命名、代码风格的可校验条款。

## 写码前（Pre-check）

1. 改视觉相关（样式、颜色、间距、圆角、字号）→ 先读《设计规范》，只引用 `src/styles/tokens.scss` 里的变量，不写魔法数字。
2. 改结构 / 新增页面或组件 → 先读《开发规则》，确认目录归属与复用阈值。
3. 改接口调用 → 先读《开发规则》的"接口契约"，走统一 axios 封装，不直接 `fetch`/裸 `axios`。

## 写码后（Self-check，逐条过）

视觉类（对照《设计规范》）
- [ ] 颜色 / 圆角 / 阴影 / 字号 / 间距全部来自 tokens 变量，无散落魔法值？
- [ ] 主色仅用于强调（按钮、链接、选中态），辅助色克制使用？
- [ ] 圆角默认 12px，卡片 12px / 按钮 12px / 输入框 12px 体系统一？
- [ ] 阴影柔和（`$shadow` 系列），无生硬黑边？
- [ ] 间距落在 8px 体系（4/8/12/16/24/32…）？

结构类（对照《开发规则》）
- [ ] 文件放在正确目录（pages/components/composables/styles）？
- [ ] 同一 UI 出现 ≥2 次已抽成可复用组件，无复制粘贴？
- [ ] 接口走 `src/api/*` + `src/utils/http.js`，mock 兜底可一键关闭？
- [ ] 命名遵守约定（页面 `PascalCase` 路由小写、组件 `PascalCase`、composable `useXxx`）？
- [ ] 无未使用的导入 / 死代码？

## 视觉校准（截图比对基准）

没有设计稿文件，**校准基准 = 《设计规范》+ `tokens.scss`**。执行：
`node scripts/run-visual-check.cjs`（自动起 dev server + Playwright 逐页截图到 `screenshots/`，
并报每页控制台错误）。截图后对照规范逐项核对：间距 / 颜色 / 字号 / 对齐，
列出与规范不符项并逐条修，重跑直到还原度 ≥ 95% 且无控制台错误。
