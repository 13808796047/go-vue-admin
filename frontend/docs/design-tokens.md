# 《设计规范》

本前端项目的视觉基准。改视觉时只引用 `src/styles/tokens.scss` 的变量，不散落魔法数字。

## 风格基调
- 现代极简：留白充足、信息密度低、单一主色强调。
- 默认背景浅灰蓝 `#f6f7fb`，卡片纯白，靠**圆角 + 柔和阴影**分层，不用粗边框。

## 颜色
| 用途 | 值 | token |
|---|---|---|
| 主色（靛蓝） | `#6366f1` | `$indigo-500` |
| 主色悬停/按下 | `#4f46e5` | `$indigo-600` |
| 主色浅底（选中/hover 背景） | `#eef2ff` | `$indigo-50` |
| 成功 | `#10b981` | `$success` |
| 警告 | `#f59e0b` | `$warning` |
| 错误 | `#ef4444` | `$danger` |
| 主文字 | `#1e1b4b` | `$text-primary` |
| 正文 | `#3f3f5a` | `$text-regular` |
| 次要/说明文字 | `#64748b` | `$text-secondary` |
| 禁用 | `#a7adb8` | `$text-disabled` |
| 边框 | `#e2e8f0` / `#eef2f8` | `$border` / `$border-light` |

- 主色**只用于强调**：主按钮、可点击链接、选中/激活态、关键图标。
- 辅助色（成功/警告/错误/信息）**克制使用**，只用于状态语义，不做大面积色块。

## 圆角（12px 体系）
- 默认 12px：卡片、按钮、输入框、下拉。
- 小元素 8px（标签、小 chips），大容器 16px（模态框）。

## 阴影（柔和）
- 卡片默认 `$shadow`：`0 4px 16px rgba(99,102,241,.10), 0 1px 4px rgba(30,27,75,.06)`。
- 悬浮/弹出 `$shadow-lg`；列表行/轻容器 `$shadow-sm`。
- 阴影带主色蓝调，不用纯黑生硬阴影。

## 间距（8px 体系）
取值只用：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`（对应 `$sp-1…$sp-8`）。
- 卡片内边距 24px；列表/表格行内垂直 12–16px；表单 label 与控件 8px。

## 字号
| 场景 | 字号 | token |
|---|---|---|
| 页面大标题 | 22px | `$fs-2xl` |
| 卡片/分组标题 | 18px | `$fs-xl` |
| 小标题/表头 | 14px 半粗 | `$fs-md` + `$fw-semibold` |
| 正文/表单 | 14px | `$fs-md` |
| 辅助说明 | 12–13px | `$fs-xs`/`$fs-sm` |
行高：标题 1.25，正文 1.5。

## 布局
- 左侧侧边栏 240px，顶栏 60px，主内容区自适应，内边距 24px。
- 内容最大不撑满，卡片栅格间距 16–24px。

## 元素速查
- 主按钮：底 `$indigo-500`、白字、圆角 12px、内边距 `12px 20px`、字 14px 半粗、hover `$indigo-600`、`$shadow-sm`。
- 次按钮：白底、`$border` 边框、`$text-regular`、hover 浅底。
- 输入框：白底、`$border`、圆角 12px、内边距 `10px 14px`、focus 主色描边 + 浅主色光晕。
- 表格：表头浅灰 `#f8f9fc`、行高 48px、行 hover `$bg-hover`、无竖线、仅浅横线分隔。
- 标签 tag：圆角 8px、浅底深字（主色浅底 = 靛色系）。
